#  Amazon Clone

##  Live Demo

https://zafar-equbal.github.io/amazon-clone/

---

##  About the Project

This project is a front-end clone of the Amazon homepage built using HTML and CSS.
It replicates the layout and design of Amazon, including the navbar, hero section, and product categories.

The main goal of this project is to practice front-end development and improve UI design skills.

---

##  Tech Stack

* HTML5
* CSS3

---

##  Feature

* 🔹 Amazon-like Navbar
* 🔹 Search Bar UI
* 🔹 Hero Section with Banner
* 🔹 Product Grid Layout
* 🔹 Clean and Structured Design

---

##  How to Run Locally

1. Clone the repository

```
git clone https://github.com/zafar-equbal/amazon-clone.git
```

2. Open the project folder
3. Run `index.html` in your browser
